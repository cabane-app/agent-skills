# Cabane agent skills

Public, self-contained [Agent Skills](https://agentskills.io/specification) for creating things in [Cabane](https://cabane.my). Each skill lives in its own folder under `skills/` and can be used without the Cabane source repository.

## Install

```sh
npx skills add cabane-app/agent-skills --skill create-cabane-model
```

Run this in a local working folder, then select your agent in the installer. The [Skills CLI](https://github.com/vercel-labs/skills) supports Codex, Claude Code, Cursor and other agents, and handles their skill directories. Node.js and npm are required for this command. Add `--global` if you want the skill available across projects.

Installation compatibility does not establish generation quality. Only the agent and tools tested below are claimed as verified.

You can describe an object or provide a real reference photo and its dimensions. Reference photos remain inputs, not part of the delivered GLB, and may be processed by your chosen AI provider.

Import the result in Cabane through **Arrange → My models → Import model (.glb file)**. Check its preview, name, Floor/Wall/Ceiling placement and Furniture or device profile. The skill produces a standard GLB; no Cabane manifest is required.

## Export and validation

The skill includes [export conventions](skills/create-cabane-model/references/export.md), independent [Blender](skills/create-cabane-model/examples/blender.py) and [Three.js](skills/create-cabane-model/examples/three.mjs) examples, and a [Python validator](skills/create-cabane-model/scripts/validate_glb.py) using only the standard library.

Limits: GLB 2.0, embedded buffers and images, metres, 10 MiB per file, 100,000 triangles and 128 mesh occurrences. Cabane accepts 100 MiB of distinct assets per house. It preserves materials and textures and displays the initial pose; animations, embedded lights and cameras are ignored. Validate locally, then check Cabane’s import preview.

```sh
python3 skills/create-cabane-model/scripts/validate_glb.py examples/desk.glb
```
